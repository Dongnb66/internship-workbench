# 实习工作台 · 浏览器助手（Chrome 扩展 · MV3）

两个功能，都不发任何网络请求：

1. **采集本页岗位** → 把当前页面上看得见的岗位读出来，粘到工作台的岗位池入库。
2. **网申一键填表** → 把工作台导出的填写包一键填进各类网申表单。

## 安装（开发者模式）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension/` 目录
4. 工具栏出现插件图标（可固定）

## 功能一：采集岗位

1. 在招聘网站打开**搜索结果列表页**，或用**岗位详情页**
2. 等岗位渲染出来（登录、验证码、滑块都由你自己完成）
3. 点插件图标 → 「采集本页岗位」
4. 结果自动复制到剪贴板；切到工作台 →「岗位池」→「批量导入」→ 粘贴 → 点「读取采集数据」

也可以点「复制 JSON」，工作台的批量导入同样认这种格式。

**能力边界（不是限制，是设计）**：只读当前页面**已经渲染出来**的内容。不翻页、不调接口、不猜接口参数、不绕登录与验证码。所以它采到的岗位，和你自己一屏一屏看过去能拿到的信息一样多 —— 它是「复制粘贴的自动化」，不是爬虫。代价是要你自己翻页；收益是你的账号不会被风控盯上。

**想要自动翻页 + 批量跑多个站点？** 用仓库里的 [`crawler/`](../crawler/README.md)（本地抓取器）：它跑在你自己的机器上，驱动你已装的 Edge / Chrome，**注入的就是本目录的 `collector.js`** —— 同一份提取实现，所以两条通道读出来的字段一定一致，区别只在「谁来点」。

想验证提取逻辑本身，见 [`fixtures/README.md`](fixtures/README.md)：里面有两个本地模拟页面和无头浏览器的跑法，也可以直接 `cd crawler && npm run selftest`（同两个夹具，自动断言）。

## 功能二：网申填表

1. 打开实习管理工作台 → 「网申填写包」→ 点「导出插件数据」，得到 `applykit.json`
2. 在目标网申页面点插件图标 → 「导入 applykit.json」（或把 JSON 内容粘进文本框点「解析并保存」）
3. 点「一键填充当前页面」
4. 已填充的输入框会用橙色描边高亮 6 秒，逐个核对后再提交

### 匹配逻辑

按可见文案（`label` / 相邻文本）+ `placeholder` + `name` + `id` + `aria-label` 做加权匹配，命中分最高者优先。
自动跳过复选框、单选框、文件上传、密码框、验证码与搜索框。
下拉框会尝试按选项文本匹配（如「本科」「2028届」）。

## 隐私

所有数据只写入 `chrome.storage.local`，仅存在你本机浏览器，扩展**不发起任何网络请求**。
权限只用 `activeTab` + `scripting` + `storage`：`activeTab` 表示只有你主动点插件的那一下，扩展才能读当前标签页，不会常驻任何网站的读取权限。

## 已知限制

- 列表页需要岗位已经渲染出来；无限滚动只采当前已加载的部分（再滚一段、再点一次即可）。
- 部分站点把岗位放在 iframe 里，采集不到，此时用工作台的「批量导入」直接粘文本。
- 网申系统里内嵌 iframe、强校验的富文本编辑器可能无法自动填充，用「网申填写包」页的复制按钮逐项粘贴。
- 省份 / 城市联动选择、日期控件通常需要手动点选。
- 页面重渲染后 `data-iwb-filled` 标记会丢失，可再点一次填充（已填内容不会被覆盖成空）。
